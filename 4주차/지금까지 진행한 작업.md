### 1. 환경 세팅

- WSL(Ubuntu) 환경에 Go 설치 → subfinder, httpx, waybackurls 설치
- WSL ↔ Windows 파일 경로(`/mnt/c/...`) 접근 방법 확인

### 2. 스코프 확인

- HackerOne Scope 페이지 CSV 다운로드로 실제 in-scope 자산 확정
    - Domain(URL) 4개: 메인 도메인 2개, 코퍼레이트 도메인 2개
    - Mobile App 4개 (Apple/Google Play)
    - eligible_for_bounty=false 2개는 제외
- ⚠️ 다른 후보 프로그램은 스코프가 완전히 비어있는(`include: []`) 상태임을 확인하고 배제

### 3. Recon (자산 발견)

```
subfinder → 서브도메인 637개 수집
httpx     → 살아있는 호스트 210개 필터링 (title, status code, 기술스택 포함)
waybackurls → 과거 URL/파라미터 수집 (params_only.txt 7858줄, sensitive_paths.txt 225줄)
```

**주목한 타겟 분류:**

- WordPress 기반 코퍼레이트 사이트 (Nginx, MySQL, WordPress VIP)
- Dev/QA/Staging 서브도메인 다수 발견
- 로그인/인증 포탈 (401 응답 다수)
- Nuxt.js/Vue.js 기반 SPA (giftcards 서비스)

### 4. WordPress REST API 분석

- `/wp-json/` 엔드포인트 전체 노출 확인 (수백 개 라우트)
- 주목할 만한 발견:
    - 사용자 열거 가능성 있는 `/wp/v2/users` 엔드포인트
    - `xmlrpc.php` 존재 확인 (GET 405, POST 프로토콜이라 실제 활성 여부 재검증 필요)
    - 커스텀 엔드포인트 중 SSRF 가능성 있는 `search/dev-tools` (url + query 파라미터 받는 POST)
    - 인증 없는 서드파티 웹훅 콜백 엔드포인트 발견

### 5. SPA JS 파일 분석 (진행 예정 단계)

- Nuxt.js 청크 파일 70개+ 목록 확보
- LinkFinder 자동화로 숨겨진 API 엔드포인트/파라미터 추출 예정
