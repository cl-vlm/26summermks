## OSINT를 활용한 Domain 및 Sub Domain 수집

### Recon

#### Subdomain Enumeration

- 공개된 API로부터 서브도메인 정보 수집
- 유관 사이트의 인증서로부터 서브도메인 정보 수집
- Bruteforce를 통한 서브도메인 정보 수집
- Search Engine Dorking ex. Google, Bing 등으로부터 서브도메인 정보 수집

#### Content Discovery

- Directory 및 Parameter Fuzzing
- 모바일 앱, 브라우저 확장 프로그램, 데스크톱 앱 등 디컴파일
- Javascript로부터 숨겨진 파라미터 하드코딩 된 크레덴셜 정보, 숨겨진 도메인 등 정보 수집
- Web Archive 탐색 및 수집
- 사용되는 기술 추출 ex. 사용하는 서버 버전, 라이브러리, 프레임워크, 방화벽 정보 등
- Search Engine Dorking ex. Google, Bing 등으로부터 URL 정보 수집

### Wappalyzer

→ 웹사이트가 사용하는 기술을 선별하는 브라우저 확장 기능

### subfinder

→ 웹사이트의 서브 도메인을 나열해준 도구

### dirsearch

→ 웹 디렉터리 경로를 스캐닝하는 도구 

### waybackurls

→ 도메인을 사용자로부터 입력받아 wayback 머신으로부터 알려진 url을 가져와서 출력해주는 기능을 함

### Wayback Machine

→ 인터넷 아카이브가 만든 디지털 타임 캡슐 (오래전부터 보존된 웹페이지를 볼 수 있음)

→ 과거부터 최근까지 저장된 URL 리스트를 볼 수 있음 → 버그 헌터는 이 정보를 보고 대상에 어떤 기능이 있고 해당 기능에는 어떤 URL을 사용하고 어떤 파라미터를 사용하는데 빠르게 식별할 수 있음

### LinkFinder

→ 자바스크립트 파일이 많고 길다면 보기에 복잡하기 때문에 정규식으로 자동화해주는 도구

### jsleak

→ LinkFinder에 몇 가지 기능이 더해져 url 부분뿐만 아니라 소스코드 안에 있는 credential 정보나 api 키, 토큰, 비밀번호 등을 탐색하는 기능을 가지고 있음

## IP Range 및 서비스 목록 수집

### NMAP

→ network mapper의 약자로 컴퓨터 네트워크의 보안검사와 네트워크 탐색을 위해 개발된 오픈소스 도구

→ 서버가 네트워크 장기들의 네트워크 인터페이스와 해당 인터페이스가 열려있는지 확인할 수 있게 해줌

### 사용방법

1. p 옵션은 타겟으로 설정된 호스트의 특정 포트를 스캔 (-p22 → 22번 포트 스캔)
2. sV 옵션으로 타겟 호스트에서 실행중인 서비스의 버전 정보를 알아내기 위해 사용 (-sV → 서비스 버전 감지)
3. O 옵션은 타겟 호스트의 운영체제를 판별하려고 할 때 사용 (-O → 운영체제 파악)
4. v 옵션은 nmap이 실행중인 작업에 대한 상세정보를 제공하게 될 때 사용해서 스캔 과정을 보다 투명하게 만듦 (-v → 상세 출력)

### 스크립트 기능

1. mse: 사용자는 복잡한 네트워크 작업을 자동화할 수 있는 스크립트를 작성하거나 제공되는 수백개의 기본 스크립트를 활용할 수도 있음
2. sc 옵션: mse는 타겟에 대한 기본 스크립트 스캔을 수행
